# CareerSync AI 🚀

**CareerSync AI** is an AI-powered career opportunity platform designed to help students discover, evaluate, and apply for relevant **scholarships, hackathons, internships, and other career opportunities** based on their profile, skills, eligibility, and interests.

The platform starts with a rule-based matching system and progressively evolves into an intelligent multi-agent career assistant.

## ✨ Key Features

- 👤 **Student Profile** — Store branch, year, category, skills, location, and resume.
- 🔎 **Opportunity Discovery** — Browse scholarships, hackathons, internships, and other opportunities.
- 🎯 **Smart Matching** — Calculate opportunity match scores based on student eligibility and requirements.
- 🤖 **AI Matcher Agent** — Analyze student profiles and opportunities using an LLM to determine eligibility, match score, and reasoning.
- 📝 **Drafting Agent** — Generate personalized SOPs, essays, and application drafts using the student's resume and opportunity requirements.
- 🌐 **Scraper Agent** — Automatically collect opportunities from selected platforms using Playwright/Puppeteer.
- ⏰ **Deadline & Follow-up Agent** — Track deadlines and provide reminders for saved or applied opportunities.
- 💾 **MongoDB Database** — Store student profiles, opportunities, and application drafts.

## 🏗️ Development Phases

### Phase 1 — Core Platform

Build the website, student profile system, opportunity listings, filters, and basic rule-based matching.

### Phase 2 — Matcher Agent

Replace rule-based matching with an LLM-powered eligibility and match-score system.

### Phase 3 — Drafting Agent

Generate personalized application drafts, SOPs, and essays based on the student's resume and opportunity requirements.

### Phase 4 — Scraper Agent

Automatically discover and normalize opportunities from selected external sources.

### Phase 5 — Deadline & Follow-up Agent

Track application deadlines and send timely reminders to students.

## 🎯 Vision

CareerSync AI aims to become a **personal career opportunity assistant for students**, reducing the time spent searching for opportunities and helping students focus on the opportunities where they have the highest chance of success.

> **Discover. Match. Apply. Succeed.**
